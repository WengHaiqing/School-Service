# 校园青蜓 · 微信小程序 MVP

这是一个可以直接导入微信开发者工具体验的原生微信小程序项目，覆盖校园任务发布、检索、自由接单、任务时效、双方完成确认、信用积分和基础风控提示。

## 立即运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `D:\School Service`。
4. AppID 可先使用测试号；本项目的 `project.config.json` 默认使用 `touristappid`。
5. 编译后即可使用。

项目不依赖 npm，也不需要先启动后端。演示数据保存在微信开发者工具的本地缓存中。

## 演示账号

首次需要执行三步认证：

- 微信登录：点击页面按钮即可调用开发态微信登录。
- 手机号：填写任意合法的中国大陆手机号。
- 短信验证码：开发态固定为 `123456`。
- 学校：任意非空名称。
- 校园卡号/学号：至少 6 位；仅保存脱敏后的尾号用于演示。

认证后可体验：

- 首页任务浏览和关键词检索。
- 发布固定金额的校园任务。
- 接取其他用户发布的任务。
- 延长自己未接单任务的有效期。
- 在“订单”中体验两个预置场景：发布者确认完成、接单者提交完成。
- 订单内聊天、站外交易风险提示、争议入口。
- 青蜓星级和校内排行。

“我的”页面提供“重置演示数据”，可恢复初始状态。

## 重要说明

当前版本是可交互 MVP，不等同于可直接商业上线的生产系统：

- 微信登录仅用于获得开发态登录结果，没有对接服务端 `code2Session`。
- 短信验证码、学生认证、内容审核、托管付款、退款和结算均为明确标注的模拟状态。
- 页面所说的“自动删除”是用户端下架/隐藏；生产系统仍需依法保存必要的身份、任务、支付和争议记录。
- 上线前需要企业主体、小程序备案、正确服务类目、隐私保护指引、真实后端、内容审核和适配业务场景的微信支付产品。
- 如果未来允许企业发布岗位、长期排班或向用人单位推荐学生，需要重新评估网络招聘服务资质。

后续接入真实服务时，可保留页面和订单状态机，将 `miniprogram/services/store.js` 替换为 `docs/API.md` 中定义的 HTTPS API。
