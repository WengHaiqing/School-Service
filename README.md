
# 校园青蜓 · 微信小程序 MVP

这是一个微信原生小程序项目，覆盖学校定位、校园任务发布、自由接单、任务时效、双方完成确认、开发态钱包、信用积分和基础风控提示。目前已经接入 CloudBase 云开发双模式数据层：默认使用正式开发环境进行多人联机，也可通过配置切回本地演示数据。

## 立即运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `D:\School Service`。
4. 当前项目已配置正式小程序 AppID。
5. 编译后即可使用。

小程序前端不依赖 npm。云端模式需要先上传并部署 `campusApi` 与 `campusSweep` 两个云函数，完整步骤见 `docs/CLOUD_SETUP.md`。

## 演示账号

首次需要执行三步认证：

- 微信登录：点击页面按钮即可调用开发态微信登录。
- 手机号：填写任意合法的中国大陆手机号。
- 短信验证码：开发态固定为 `123456`。
- 学校：任意非空名称。
- 校园卡号/学号：至少 6 位；仅保存脱敏后的尾号用于演示。

认证后可体验：

- 首页按省、市、学校定位，以双列卡片浏览本校任务。
- 使用“校园跑腿、跳蚤市场、自由任务”三个分类发布固定金额任务。
- 发布页仅保留分类、标题、50字备注、金额和接单有效期。
- 在“我的”页面体验开发态钱包充值、提现以及发布余额校验。
- 接取其他用户发布的任务。
- 延长自己未接单任务的有效期。
- 在“订单”中体验两个预置场景：发布者确认完成、接单者提交完成。
- 订单内聊天、站外交易风险提示、争议入口。
- 青蜓星级和校内排行。

本地模式下，“我的”页面提供“重置演示数据”，可恢复初始状态。

## 重要说明

当前版本是云端联机 MVP，不等同于可直接商业上线的生产系统：

- 云函数使用微信 OpenID 建立真实的多用户隔离；短信验证码、学生认证、内容审核、钱包充值提现、托管付款、退款和结算仍为明确标注的模拟状态。
- 手机号和校园卡号仅保存哈希及脱敏尾号，但开发态验证码固定为 `123456`，不能用于公开发布。
- 页面所说的“自动删除”是用户端下架/隐藏；生产系统仍需依法保存必要的身份、任务、支付和争议记录。
- 上线前需要企业主体、小程序备案、正确服务类目、隐私保护指引、真实后端、内容审核和适配业务场景的微信支付产品。
- 如果未来允许企业发布岗位、长期排班或向用人单位推荐学生，需要重新评估网络招聘服务资质。

如需暂时回到离线演示，可将 `miniprogram/config/env.js` 中的 `USE_CLOUD` 改为 `false`。公开内测前必须替换开发态短信和学生认证，并完成管理后台、内容审核、隐私规则和支付资质。
