# 校园青蜓 MVP 产品规则

## 第一版范围

- 用户：年满 18 周岁的在校学生。
- 场景：同一学校内的一次性校园任务。
- 价格：固定金额，不支持面议和竞价。
- 角色：需求发布者、任务接单者、平台客服。
- 暂缓：企业招聘、长期排班、二手商品、服务挂牌、跨校接单、现金排行榜和余额钱包。

## 核心状态机

### 公开任务

```text
待审核 → 待接单 → 已接单
                ↘ 到期下架
```

被接单后立即退出公开任务大厅。任务的“接单截止时间”和订单的“履约截止时间”是两个独立字段。

### 订单

```text
进行中 → 接单者提交 → 发布者确认 → 已完成
   │           │           └ 24小时未操作 → 自动完成
   │           └ 有异议 → 争议处理中
   └ 超时 → 顺延24小时 → 仍未提交 → 取消/退款
```

争议状态不得自动结算、退款或删除，应由客服依据证据处理。

## 用户端删除与记录保留

- 到期未接单：从公开大厅移除。
- 接单成功：公开任务立即移除，订单仅双方可见。
- 完成或取消：保留 7 天用户可见期，之后从普通订单列表隐藏。
- 后台：依法保存最小必要的身份、任务、支付、消息、投诉和审计记录。

页面不能宣称“服务器完全不保留历史记录”。

## 星级

星级建议由以下指标组成：

- 真实完成率。
- 按时提交率。
- 主动取消率。
- 有效评价。
- 经客服核实的投诉和违规。

单纯“发生争议”不能直接扣双方分；否则恶意投诉会成为攻击工具。

## 处罚梯度

- 信息不规范：下架、修改。
- 首次轻微虚假：警告、信用影响。
- 多次虚假或爽约：限期限制功能。
- 欺诈、违法、严重骚扰、重复重大违规：永久封禁。
- 涉嫌违法犯罪：保存必要证据并依法报告。

所有处罚应向用户说明原因并提供申诉入口。
