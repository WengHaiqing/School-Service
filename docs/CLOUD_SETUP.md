# 校园青蜓 CloudBase 部署指引

## 当前环境

- 正式 AppID：已写入 `project.config.json`。
- 云环境 ID：已写入 `miniprogram/config/env.js`。
- 云端模式：`USE_CLOUD: true`。

AppID 和环境 ID 不是密钥，可以进入代码仓库。AppSecret、微信支付 API 密钥、商户证书、腾讯云 SecretId/SecretKey 绝对不能写入项目或提交 Git。

## 1. 在开发者工具中确认环境

1. 重新打开 `D:\School Service`。
2. 点击“详情”，确认项目使用正式 AppID。
3. 点击“云开发”，确认能看到环境 `cloud1-d1gdlvruj6129b660`。
4. 调试基础库选择较新的稳定版本。

## 2. 上传并部署云函数

项目树应显示 `cloudfunctions` 云函数根目录。

依次操作：

1. 右键 `cloudfunctions/campusApi`。
2. 选择“上传并部署：云端安装依赖”。
3. 等待状态显示部署成功。
4. 右键 `cloudfunctions/campusSweep`。
5. 选择“上传并部署：云端安装依赖”。

不要选择“所有文件”里跳过依赖安装，因为两个函数都需要 `wx-server-sdk`。

`campusSweep/config.json` 声明了每 10 分钟触发一次的定时器。部署后在云开发控制台的“云函数 → campusSweep → 触发器”中确认存在：

```text
campus-lifecycle-every-10-minutes
```

如果没有自动创建，手动新增定时触发器，Cron 配置为：

```text
0 */10 * * * * *
```

## 3. 初始化数据库

部署 `campusApi` 后重新编译小程序。第一次打开时，前端会调用 `bootstrap`，尝试创建以下集合：

- `users`
- `tasks`
- `orders`
- `messages`
- `reports`
- `system_meta`

如果控制台提示集合不存在，说明当前云函数 SDK 不支持自动创建集合，请在“云开发 → 数据库”中手动创建上述 6 个集合，然后重新编译。

### 数据库权限

所有业务读写都通过云函数执行。每个集合的客户端权限应设置为：

```text
所有用户不可直接读写（仅云函数/管理员）
```

不要设置成“所有用户可读写”，否则用户可以绕过订单状态机直接修改金额或订单状态。

### 推荐索引

数据量增长前，在数据库控制台添加：

- `users`：`openid` 唯一索引。
- `tasks`：`status`、`publisherId`、`expiresAt` 普通索引。
- `orders`：`publisherId`、`runnerId`、`status` 普通索引。
- `messages`：`orderId`、`createdAt` 普通索引。
- `reports`：`status`、`createdAt` 普通索引。

创建 `openid` 唯一索引前，先确认测试阶段没有重复用户记录。

## 4. 单账号冒烟测试

第一次打开小程序：

1. 进入认证页。
2. 点击微信登录。
3. 输入任意合法格式的开发态手机号。
4. 验证码填写 `123456`。
5. 填写学校、校区和至少 6 位校园卡号/学号。
6. 发布一个固定金额任务。
7. 在云数据库 `tasks` 集合确认出现记录。

云端只保存手机号和校园卡号的哈希、脱敏尾号，不保存前端输入的原文。

## 5. 双账号联机测试

1. 在公众平台“成员管理”中添加第二个微信为体验成员或开发者。
2. 账号 A 完成认证并发布任务。
3. 账号 B 在另一台手机或另一个开发者工具账号中完成认证。
4. 账号 B 应看到账号 A 的任务并接单。
5. 账号 A 刷新后应看到订单，公开任务应消失。
6. 账号 B 提交完成说明。
7. 账号 A 确认完成或发起争议。
8. 检查双方订单状态、聊天消息和云数据库记录一致。

重点并发测试：两个账号尽量同时点击同一个任务的“立即接单”，只能有一个成功，另一个应收到“任务已被接取或已下架”。

## 6. 常见错误

### 云函数尚未部署

提示包含 `FUNCTION_NOT_FOUND` 时，重新执行“上传并部署：云端安装依赖”。

### 无法获取微信用户身份

确认开发者工具项目使用正式 AppID，并且云环境已经与该小程序关联。

### 数据库集合不存在

按照第 3 节手动创建 6 个集合。

### 权限不足

确认当前微信已加入小程序的开发成员，并确认云环境属于当前正式 AppID。

### 页面没有本地演示任务

云端环境默认是干净数据库，不会自动复制旧的本地演示任务。请用账号 A 发布第一条云端任务，再用账号 B 接单。
